# 01-scope — home (홈)

> 참고: PRD에서 홈 화면을 직접 설명하는 곳은 5절(섹션 목록)과 16절 핵심 화면 목록의 "홈" 한 단어뿐이다. 홈의 목적·구성·역할별 차이는 PRD에 적혀 있지 않다. 아래 표는 PRD가 홈에 간접적으로 걸어 두는 제약만 담고, 나머지는 질문으로 돌렸다.

## 유지할 콘텐츠·정책
| 항목 | PRD 근거 |
| --- | --- |
| 홈은 MVP 핵심 화면 목록에 포함된다 | 16절 |
| 홈에서 진입 가능한 섹션은 무료 학습자료, 유료 멤버 자료실, 스킬 라이브러리, 내 학습, 내 자산이다 | 5절, 9절 |
| 허들링 픽 섹션은 MVP에서 제외한다. 홈에 허들링 픽 노출을 두지 않는다 | 5절, 6-6, 9절 범위 결정 1 |
| 구매자 흐름·구매한 자산은 이번 범위 밖이다 | 3-5, 5절, 6-6, 9절 범위 결정 1 |
| 피드백(피드백 기록·도착 알림)은 MVP 제외다. 홈에 피드백 관련 정보를 두지 않는다 | 5절, 6-4, 6-8, 9절 범위 결정 4 |
| 판매 수익 정보는 MVP 제외다 (Phase 3) | 5절, 6-5, 7-4 |
| 콘텐츠에는 무료/유료 표시가 있어야 한다 | 6-1 |
| 유료 콘텐츠 미리보기와 앱 가입/유료 전환 CTA가 필요하다 | 6-1, 7-2 |
| 무료 콘텐츠 카테고리는 AI 실무, Figma + AI, 바이브코딩, 자동화, 콘텐츠 제작, 1인 사업가 운영 6개다 | 6-1 |
| 비회원·무료·유료·판매 승인·운영자 권한에 따라 접근 범위가 다르다. 권한 밖 자료는 접근이 제한된다 | 6-2, 7절 |
| "판매 신청"은 판매 승인 회원(seller)에게만 선택 가능하다. 그 외 역할의 홈에 판매 신청 진입을 노출하지 않는다 | 6-5, 7-4, 14절 |
| 실시간 채팅과 앱 내 커뮤니티 피드는 두지 않는다. 대화는 Discord가 담당한다 | 4절, 9절, 14절 |
| 알림성 정보는 상태 변화 중심으로 하고 과도하게 보내지 않는다 | 6-8 |
| 비주얼은 design.md 규칙(모노크롬 + 단일 액센트, 그림자 없음, pill)을 따른다 | 14절, 15절 |
| 자료실처럼 보이기보다 실험실·자산 라이브러리의 느낌이 살아야 한다 | 15절 디자인 완성도 |

## 변경 가능한 영역
| 항목 | PRD 근거 |
| --- | --- |
| 홈 안의 섹션 배치와 순서 (5절은 "최소한" 가져야 할 섹션만 나열하고 순서를 정하지 않는다) | 5절 |
| 홈에서 강조할 정보의 우선순위 (PRD가 홈의 1순위 정보를 정하지 않는다) | 5절, 16절 |
| 무료 회원의 유료 전환 CTA 위치와 형태 (CTA 필요는 정해져 있고 위치는 정해져 있지 않다) | 6-1 |
| 카테고리 6개를 홈에서 드러내는 방식 (필터·칩·카드 등) | 6-1 |
| 학습 흐름(콘텐츠 → 미션 → 제출 → 자산)을 홈 구조로 드러내는 방식 | 15절 학습 흐름의 완성도 |

| 3 | 운영자(admin)의 홈은 이 화면 범위에 포함되는가, 아니면 운영자 검수 화면이 진입점인가? | 16절 핵심 화면에 "홈"과 "운영자 검수 화면"이 따로 있고, 운영자 홈 여부는 적혀 있지 않다 | (미답변) |
| 4 | 무료 회원의 홈에 "내 학습", "내 자산" 섹션이 보이는가? 보인다면 잠금 상태로 보이는가, 숨기는가? | 5절은 섹션 전부를 나열하지만 7-2 무료 회원 권한에는 미션 "일부 참여"만 있고 내 자산 등록은 7-3(유료)부터다 | (미답변) |
| 5 | 홈에 현재 미션·제출 상태, 최근 본/저장한 자료, 알림을 노출하는가? 노출한다면 어느 정보를 우선하는가? | 6-2(최근 본/저장한 자료), 6-4(현재 미션, 제출 상태), 6-8(알림)이 기능으로만 있고 노출 위치가 정해져 있지 않다 | (미답변) |

## 확인하지 못한 기존 자산
- huddling.club: WebFetch가 HTTP 403 Forbidden을 반환해 내용을 확인하지 못함.
- Discord: 접근 수단이 없어 확인하지 못함.
- 강의/라이브/워크숍 자료: 접근 경로가 주어지지 않아 확인하지 못함.
- 프롬프트/스킬 파일: 접근 경로가 주어지지 않아 확인하지 못함.
- huddling.ai: WebFetch로 접근했고 메뉴 6개(AI & Figma Tips, AI Report, Prompt Pedia, Kiosk (Food), UX/UI Design Study, Figma Resources), 카테고리 카드 6개, "HuddlingClub 3기 오픈" 배너를 확인함. 응답은 이 페이지를 HuddlingClub으로 부르고 있어 huddling.ai와 huddling.club의 구분은 확인하지 못함. 약관·개인정보 등 정책 문구는 응답에서 보이지 않음. 요약 응답만 받았으므로 화면 구성 세부는 확인하지 못함.
