# 01-scope — home (홈)

> 참고: PRD에서 홈 화면을 직접 언급하는 곳은 16절 핵심 화면 목록의 "홈" 한 단어뿐이다. 홈의 목적·구성·역할별 차이는 PRD에 적혀 있지 않다. 아래 표는 PRD 문장이 실제로 말하는 것(`직접`), PRD 절을 근거로 내가 추론한 것(`해석`), 질문 1~9의 답변(가정)에 기댄 것(`가정`)을 구분해 적는다.
>
> 주의: 질문 1~9의 답변은 하이서가 확인한 것이 아니다. 사용자가 "기본값으로 진행"하라고 해서 오케스트레이터가 PRD에서 가장 가까운 쪽으로 고른 가정이다. 하이서가 확인하면 바뀔 수 있다. `가정` 항목은 모두 그 전제 위에 있다.

## 유지할 콘텐츠·정책
| 항목 | PRD 근거 | 근거 유형 |
| --- | --- | --- |
| 홈은 제출물 기준의 핵심 화면 목록에 포함된다 | 16절 | 직접 |
| 앱의 섹션은 무료 학습자료, 유료 멤버 자료실, 스킬 라이브러리, 내 학습, 내 자산이다 (허들링 픽은 MVP 제외) | 5절, 9절 | 직접 |
| 홈이 위 섹션들로 들어가는 진입점 역할을 한다 (5절·9절은 앱의 섹션 목록과 MVP 범위일 뿐 "홈에서 진입"을 말하지 않는다) | 5절, 16절 | 해석 |
| 허들링 픽 노출은 이번 범위에 포함하지 않는다 (홈 화면을 따로 언급하지는 않는다) | 5절, 6-6, 9절 범위 결정 1 | 직접 |
| 구매자 흐름·구매한 자산은 이번 범위 밖이다 | 3-5, 5절, 6-6, 9절 범위 결정 1 | 직접 |
| 미션 피드백(피드백 기록·도착 알림)은 MVP 제외이고, 제출 상태는 `작성 중` / `제출 완료`만 둔다 | 5절, 6-4, 6-8, 9절 범위 결정 4 | 직접 |
| 홈에 피드백 관련 정보(피드백 상태·알림)를 두지 않는다 (PRD는 기능 제외만 말하고 홈은 언급하지 않는다) | 5절, 6-4, 6-8 | 해석 |
| 판매 수익은 Phase 3이다 | 5절, 6-5, 7-4 | 직접 |
| 무료 학습자료의 콘텐츠에는 무료/유료 표시가 있어야 한다 | 6-1 | 직접 |
| 홈이 콘텐츠를 보여줄 때도 무료/유료 표시를 유지한다 (6-1은 무료 학습자료 섹션의 요구사항이다) | 6-1 | 해석 |
| 무료 학습자료에는 유료 콘텐츠 미리보기와 앱 가입/유료 전환 CTA가 필요하다 | 6-1, 7-1, 7-2 | 직접 |
| 무료 콘텐츠 카테고리는 AI 실무, Figma + AI, 바이브코딩, 자동화, 콘텐츠 제작, 1인 사업가 운영 6개다 | 6-1 | 직접 |
| 역할은 비회원·무료·유료·판매 승인·운영자로 나뉘고 권한이 다르다. 유료 멤버 자료실은 멤버십 권한에 따라 접근이 제한된다 | 7절, 6-2 | 직접 |
| 비회원은 공개 콘텐츠 일부 열람과 회원가입 CTA 확인이 가능하다. 무료 회원은 무료 학습자료 열람, 무료 미션 일부 참여, 유료 자료 미리보기가 가능하다 | 7-1, 7-2 | 직접 |
| 판매 신청은 판매 승인 회원(seller)만 선택할 수 있다 | 6-5(5번), 7-4, 9절 범위 결정 2 | 직접 |
| seller가 아닌 역할의 홈에는 판매 신청 진입을 노출하지 않는다 (PRD는 "선택 가능" 권한만 제한하고 홈 노출은 말하지 않는다) | 6-5, 7-4 | 해석 |
| 실시간 채팅과 앱 내 커뮤니티 피드는 MVP 1차에서 제외 가능하고, 대화는 Discord가 담당한다 | 4절, 9절, 14절 | 직접 |
| 앱 알림의 필수 종류는 새 미션 오픈, 제출 마감 임박, 판매 신청 상태 변경, 자산 승인/반려다. 알림은 과도하게 보내지 않고 상태 변화 중심이다 | 6-8 | 직접 |
| 현재 미션 보기·제출 상태 확인은 필수 기능이다. 최근 본/저장한 자료는 유료 멤버 자료실의 필수 기능이다 (홈 노출은 말하지 않는다) | 6-4, 6-2 | 직접 |
| 학습 흐름(미션 수행 → 제출 → 자산으로 남기기)이 화면 구조로 드러나야 한다. 피드백 단계는 MVP 제외다. 어느 화면이 담당하는지는 PRD에 없다 | 15절 학습 흐름의 완성도, 6-4(6번) | 직접 |
| 비주얼은 design.md 규칙(모노크롬 캔버스 + 단일 액센트, 그림자 없는 깊이, pill)을 따른다 | 14절, 15절 | 직접 |
| 자료실처럼 보이기보다 실험실·자산 라이브러리의 느낌이 살아야 한다 | 15절 디자인 완성도 | 직접 |
| 홈은 학습 흐름의 시작점이다 (콘텐츠 탐색 → 미션 → 제출 → 자산) | 질문 1 답변(가정) | 가정 |
| 홈은 하나이고, 권한에 따라 일부가 잠기는 방식이다. 역할별 홈을 따로 설계하지 않는다 | 질문 2 답변(가정) | 가정 |
| 운영자(admin) 홈은 이 화면 범위 밖이다. 운영자 진입점은 운영자 검수 화면이다 | 질문 3 답변(가정) | 가정 |
| 무료 회원에게도 내 학습·내 자산 섹션이 보이되 잠금 상태로 보인다 (숨기지 않는다) | 질문 4 답변(가정) | 가정 |
| 홈은 현재 미션·제출 상태와 최근 본/저장한 자료를 노출한다 | 질문 5 답변(가정) | 가정 |
| 위 두 정보 중 미션이 우선이다 | 질문 5 답변(가정) | 가정 |
| 알림은 홈 본문에 두지 않는다 (알림 목록을 홈에 넣지 않는다) | 질문 5·8 답변(가정) | 가정 |
| 알림 확인은 홈 본문과 별도의 진입점으로 둔다 | 질문 8 답변(가정) | 가정 |
| 홈의 카테고리는 6-1의 6개만 쓴다. 기존 huddling.ai 메뉴 구성은 참고만 하고 가져오지 않는다 | 질문 6 답변(가정) | 가정 |
| 무료 회원의 미션 영역: 무료 미션이 있으면 홈에 노출하고 유료 미션은 잠금으로 보인다 | 질문 7 답변(가정) | 가정 |
| 비회원 홈: 미션·최근 본 영역은 숨기고 가입 CTA로 대체한다 | 질문 9 답변(가정) | 가정 |

## 남은 모호함 (질문이 아닌 가정)
- 무료 회원의 미션 참여 범위: 질문 4·7 답변(가정)은 내 학습을 잠그고 무료 미션은 홈에 노출한다. 7-2는 "무료 미션 일부 참여"를 허용하지만 6-4는 미션 제출을 유료 멤버 기능처럼 적는다(7-3도 미션 제출을 유료 회원에 둔다). 무료 미션이 열람만인지 제출까지인지, 무료 미션이 실제로 존재하는지(8절 Mission에 access_level 필드는 있다)는 PRD에 없다. 충돌은 아니고 범위가 비어 있다. 홈은 "무료 미션이 있으면 노출"을 전제로 그리고, 제출 가능 여부는 미정으로 둔다.
- 비회원 홈의 존재 자체: 9절은 로그인을 MVP 필수로 두고 6-1·7-1은 비회원 열람을 허용한다. 비회원이 앱에서 홈을 보는지, 공개 웹(huddling.ai)에서 보는지는 PRD에 없다. 질문 9 답변(가정)은 앱 홈에 비회원 상태가 있다고 전제한다.
- 알림 별도 진입점의 실체: 질문 8 답변(가정)은 별도 진입점을 두라고만 한다. 그 진입점이 아이콘인지 별도 화면인지 PRD에 없고, 16절 핵심 화면 목록에도 알림 화면이 없다.
- 최근 본/저장 자료의 범위: 6-2는 이를 유료 멤버 자료실의 기능으로 적는다. 무료 회원이 무료 학습자료에 대해 최근 본/저장을 갖는지, 홈의 이 영역이 어떤 자료를 담는지는 PRD에 없다(6-1 본문은 앱에서 "저장"이 가능해야 한다고만 적는다).
- 판매 승인 회원 홈의 판매 신청 진입: 판매 신청은 내 자산에서 공개 범위로 선택하는 흐름(6-5)이고, 홈에 별도 진입을 두는지는 PRD에 없다. 위 표는 이를 `해석`으로 처리했다.
